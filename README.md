# Torrent Search Engine

A simple full-stack torrent search engine built using Node.js, Express, HTML, CSS, and JavaScript.

## Features
- Search torrents
- View seeders
- Magnet links
- Responsive UI

## Tech Stack
- Node.js
- Express
- HTML
- CSS
- JavaScript

## Run Locally

```bash
npm install
node server.js
