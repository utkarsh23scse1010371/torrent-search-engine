# Torrent Search Engine

A simple full-stack torrent search engine built using Node.js, Express, HTML, CSS, and JavaScript.

---

## Demo Preview

![Torrent Search Engine Demo](demo.png)

---

## Features

- Search torrents instantly
- View torrent size
- View seeders and leechers
- Magnet download links
- Responsive dark UI
- Full-stack application

---

## Tech Stack

- Node.js
- Express.js
- HTML5
- CSS3
- JavaScript

## Installation

Clone repository:

```bash
git clone https://github.com/your-username/torrent-search-engine.git
```

Move into project folder:

```bash
cd torrent-search-engine
```

Install dependencies:

```bash
npm install
```

Run server:

```bash
node server.js
```

Open browser:

```txt
http://localhost:3000
```
